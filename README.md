# รวมระบบงาน ป. (ตำรวจภูธรภาค 7)

หน้าเว็บอยู่ที่ **GitHub Pages** ส่วนหลังบ้าน (เก็บข้อมูล/อัปโหลดไฟล์/รหัส admin) ยังเป็น **Google Apps Script** ทำหน้าที่เป็น API

```
ผู้ใช้ → GitHub Pages (docs/) → เรียก API → Google Apps Script (gas/) → Google Sheets + Drive
```

| โฟลเดอร์/ไฟล์ | ใช้ทำอะไร |
|---|---|
| `docs/index.html`, `docs/app.js` | หน้าเว็บ (ขึ้น GitHub Pages) |
| `docs/config.js` | **ที่เดียวที่ต้องแก้** ใส่ที่อยู่ API (URL ลงท้าย `/exec`) |
| `gas/Code.gs`, `gas/appsscript.json` | หลังบ้าน (วางใน Apps Script) |
| `SECURITY.md` | ข้อห้ามและข้อควรทำด้านความปลอดภัย (อ่านก่อนใช้งานจริง) |

---

## ติดตั้งครั้งแรก

### 1. สร้าง repo (แบบ Public)
1. เข้า GitHub กด **New repository**
2. ตั้งชื่อ เช่น `rtp7-hub` เลือก **Public** แล้วกด **Create repository**

### 2. อัปโหลดไฟล์
1. ในหน้า repo กด **Add file → Upload files**
2. ลากไฟล์และโฟลเดอร์ทั้งหมดในชุดนี้ลงไป (`docs`, `gas`, `README.md`, `SECURITY.md`, `.gitignore`)
   - ต้องเห็นไฟล์ `docs/.nojekyll` ด้วย (ถ้าไฟล์ที่ขึ้นต้นด้วยจุดไม่ถูกอัปโหลด ให้กด **Add file → Create new file** ตั้งชื่อ `docs/.nojekyll` แล้วเว้นว่างไว้ กด Commit)
3. กด **Commit changes**

### 3. เปิด GitHub Pages
1. ไปที่ **Settings → Pages**
2. ตรง **Build and deployment** เลือก **Source: Deploy from a branch**
3. เลือก Branch = **main** และโฟลเดอร์ = **/docs** แล้วกด **Save**
4. รอ 1-2 นาที จะได้ลิงค์เว็บ เช่น `https://ชื่อบัญชี.github.io/rtp7-hub/` (ยังโหลดข้อมูลไม่ได้ จนกว่าจะทำข้อ 4-8 เสร็จ)

### 4. วางโค้ดใน Apps Script
1. เข้า <https://script.google.com> ด้วย **บัญชี Google เฉพาะกิจสำหรับระบบนี้** (ดู `SECURITY.md`) แล้วกด **โปรเจกต์ใหม่**
2. เปิดไฟล์ `Code.gs` ในโปรเจกต์ ลบของเดิมทิ้ง แล้ววางเนื้อหาจาก `gas/Code.gs`
3. เปิดไฟล์ manifest: ไปที่ **Project Settings (รูปเฟือง)** ติ๊ก **Show "appsscript.json" manifest file in editor** แล้วกลับมาที่ Editor เปิด `appsscript.json` วางเนื้อหาจาก `gas/appsscript.json`
4. กด **Save**

### 5. ตั้งรหัส admin (ห้ามเขียนในโค้ด)
1. ไปที่ **Project Settings → Script Properties → Add script property**
2. Property = `ADMIN_PIN` , Value = รหัส admin เป็นตัวเลข 8-12 หลัก ห้ามใช้ 5555 หรือรหัสเดิมของระบบ v1.2 และไม่ซ้ำกับระบบอื่น
3. กด **Save script properties**

> ถ้าไม่ตั้ง `ADMIN_PIN` ระบบจะ **ไม่ยอมให้เข้าโหมด admin** (ล็อกไว้เพื่อความปลอดภัย)

### 6. สร้างฐานข้อมูลและอนุญาตสิทธิ์
1. ใน Editor เลือกฟังก์ชัน **`setupDatabase`** ที่แถบด้านบน แล้วกด **Run**
2. กด **Review permissions** → เลือกบัญชี → **Advanced → Go to ... (unsafe)** → **Allow**
3. เมื่อรันเสร็จ ดูที่ **Execution log** จะมีลิงค์ชีตและโฟลเดอร์ที่ระบบสร้างให้

### 7. Deploy เป็น Web app
1. กด **Deploy → New deployment** → ไอคอนเฟือง เลือก **Web app**
2. ตั้งค่า **Execute as: Me** และ **Who has access: Anyone**
   - ต้องเลือก **Anyone** (ไม่ใช่ Anyone with Google account) ไม่งั้นหน้าเว็บจะเชื่อมต่อไม่ได้
3. กด **Deploy** แล้ว **คัดลอก Web app URL** (ลงท้ายด้วย `/exec`)

### 8. ใส่ URL ใน `docs/config.js`
1. ใน GitHub เปิดไฟล์ `docs/config.js` กดรูปดินสอ (Edit)
2. วาง URL ที่คัดลอกไว้ระหว่างเครื่องหมายคำพูด:
   ```js
   window.APP_CONFIG = {
     API_URL: 'https://script.google.com/macros/s/xxxxxxxx/exec'
   };
   ```
3. กด **Commit changes** แล้วรอ 1-2 นาที

### 9. เปิดเว็บทดสอบ
เปิดลิงค์ GitHub Pages ดูวิธีทดสอบด้านล่าง

## วิธีอัปเดตภายหลัง

**แก้หน้าเว็บ (`docs/`)**: แก้ไฟล์ใน GitHub แล้ว Commit รอ 1-2 นาที (ถ้าหน้าเว็บยังเป็นของเก่า ให้กด Ctrl+F5 หรือรีเฟรชแรงๆ)

**แก้หลังบ้าน (`gas/Code.gs`)**: วางโค้ดใหม่ใน Apps Script แล้ว **ต้องออกเวอร์ชันใหม่ ไม่เช่นนั้นการแก้ไขจะไม่มีผล**
1. กด **Deploy → Manage deployments**
2. กดรูปดินสอ (Edit) ที่ deployment เดิม
3. ตรง **Version** เลือก **New version** แล้วกด **Deploy**

> ห้ามกด **New deployment** ใหม่ เพราะจะได้ URL ใหม่ และต้องไปแก้ `docs/config.js` ทุกครั้ง การแก้ deployment เดิมจะได้ URL เดิม

---

## วิธีทดสอบ

1. **ตรวจหลังบ้าน**: เปิด URL `/exec` ในเบราว์เซอร์ ต้องเห็นข้อความรูปแบบ `{"ok":true,"app":"รวมระบบงาน ป.","version":"v2.1 (8 พ.ย. 69)"}`
2. **หน้าแรก**: เปิดเว็บ GitHub Pages ต้องเห็นไอคอนระบบ 7 ระบบ (ถ้าเห็นข้อความ "ยังไม่ได้ตั้งค่าที่อยู่ระบบหลังบ้าน" แปลว่ายังไม่ได้ทำข้อ 8)
3. **โหมด admin**: กดรูปกุญแจ ใส่ `ADMIN_PIN` ที่ตั้งไว้ → ต้องเข้าโหมด admin ได้ / ใส่ผิดต้องขึ้น "รหัส PIN ไม่ถูกต้อง"
4. **เพิ่มข้อมูล**: ใน ตั้งค่า → จัดการระบบ ลองแก้ลิงค์ระบบ แล้วกลับมาหน้าแรกต้องเห็นการเปลี่ยนแปลง (รอได้ถึง 1 นาที เพราะมีแคช)
5. **อัปโหลดไฟล์**: ใน ตั้งค่า → เอกสารดาวน์โหลด ลองอัปโหลดไฟล์เล็กๆ แล้วกดดาวน์โหลดจากหน้าแรก
6. **สถิติ**: ใน ตั้งค่า → สถิติการใช้งาน ต้องแสดงตัวเลข

## ถ้ามีปัญหา

| อาการ | วิธีแก้ |
|---|---|
| เห็น "ยังไม่ได้ตั้งค่าที่อยู่ระบบหลังบ้าน" | ใส่ `API_URL` ใน `docs/config.js` (ข้อ 8) |
| เห็น "ที่อยู่ระบบหลังบ้านไม่ถูกต้อง" | URL ต้องขึ้นต้น `https://script.google.com/` และลงท้าย `/exec` |
| เห็น "เชื่อมต่อระบบหลังบ้านไม่ได้" | ตรวจอินเทอร์เน็ต และตรวจว่า Deploy เป็น Who has access: **Anyone** |
| เข้า admin ไม่ได้ ขึ้น "ยังไม่ได้ตั้งรหัส admin" | ตั้ง `ADMIN_PIN` ใน Script Properties (ข้อ 5) |
| แก้ `Code.gs` แล้วไม่เปลี่ยน | ต้องออก New version ที่ Manage deployments (หัวข้ออัปเดต) |
| ใส่ PIN ผิดหลายครั้งแล้วถูกล็อก | รอ 10 นาที |
| หลังบ้านตอบช้า (รอ 5-15 วินาที) | เป็นเรื่องปกติ เกิดตอนเปิดครั้งแรกหรือหลังไม่มีคนใช้นาน รอสักครู่แล้วจะเร็วขึ้นเอง |
| โดนล็อก PIN บ่อยผิดปกติ | แปลว่าอาจมีคนพยายามเดารหัส ให้เปลี่ยน `ADMIN_PIN` ใน Script Properties ทันที |

> **ข้อจำกัดของ Apps Script:** ใครก็ตามที่ใส่ PIN ผิด 10 ครั้ง จะทำให้ admin ถูกล็อก 10 นาทีสำหรับทุกคน เพราะ Apps Script แยกว่าใครมาจากเครื่องไหนไม่ได้ ถ้าเกิดบ่อยให้เปลี่ยน `ADMIN_PIN`

## ย้ายจากระบบเดิม v1.2 (ข้อมูลไม่หาย)

**ทางที่ 1 (ง่ายที่สุด): ใช้โปรเจกต์ Apps Script เดิม**
1. เปิดโปรเจกต์ Apps Script ของระบบเดิม
2. เปิดไฟล์ `Code.gs` ลบของเดิมทิ้ง แล้ววางเนื้อหาจาก `gas/Code.gs` (ไฟล์ใหม่ในนี้)
3. ลบไฟล์ `Index.html` ออกจากโปรเจกต์ (กดจุดสามจุดข้างชื่อไฟล์ → Delete)
4. ไปที่ **Project Settings → Script Properties** เพิ่ม `ADMIN_PIN` ตามข้อ 5 (ตัวเลข 8-12 หลัก ห้ามใช้ 5555 หรือรหัสเดิม)
5. กด **Deploy → Manage deployments** → รูปดินสอที่ deployment เดิม → ตรง Version เลือก **New version** → **Deploy**
6. **แจ้งผู้ใช้ทุกคน**: ลิงค์ `/exec` เดิมจะตอบเป็นข้อความ JSON ไม่ใช่หน้าเว็บอีกต่อไป ให้เปิดใช้ลิงค์ **GitHub Pages** แทน (และใส่ URL `/exec` เดิมใน `docs/config.js` ตามข้อ 8)

**ทางที่ 2: สร้างโปรเจกต์ใหม่ แต่ยังใช้ข้อมูลเดิม**
1. เปิดโปรเจกต์เดิม → **Project Settings → Script Properties** แล้วจดค่า `SS_ID` และ `FOLDER_ID`
2. ทำตามข้อ 4 สร้างโปรเจกต์ใหม่ วางโค้ด
3. **ก่อนกด Run `setupDatabase`** ให้ไปที่ Script Properties ของโปรเจกต์ใหม่ เพิ่ม `SS_ID` และ `FOLDER_ID` ด้วยค่าที่จดไว้ (ไม่งั้นจะได้ชีตใหม่ที่ว่างเปล่า) และบัญชี Google ที่ใช้ในโปรเจกต์ใหม่ต้องเป็นเจ้าของ หรือมีสิทธิ์แก้ไขชีตและโฟลเดอร์เดิมด้วย ไม่งั้นระบบอาจสร้างโฟลเดอร์ใหม่แทนโดยไม่แจ้งเตือน
4. ตั้ง `ADMIN_PIN` (ข้อ 5) แล้วทำข้อ 6 เป็นต้นไปตามปกติ
